## Purpose

Run Hermes Agent on peterspav as an always-on agent that pim reaches over
Matrix and observes through a dashboard, using the OpenCode Go subscription
for its model.

## ADDED Requirements

### Requirement: Always-on service on peterspav

peterspav SHALL run Hermes Agent as a system service that starts at boot
without a login session and restarts after a failure.

#### Scenario: After a reboot

- **WHEN** peterspav boots and nobody logs in
- **THEN** the Hermes service is running

#### Scenario: Crash

- **WHEN** the Hermes process exits unexpectedly
- **THEN** systemd starts it again

### Requirement: Model from OpenCode Go

Hermes SHALL use the OpenCode Go endpoint as a custom OpenAI-compatible
provider, with an API key supplied from agenix and never stored in the Nix
store.

#### Scenario: Answering a prompt

- **WHEN** pim sends Hermes a message
- **THEN** the reply is generated by the configured OpenCode Go model

#### Scenario: Secret handling

- **WHEN** the system closure of peterspav is inspected
- **THEN** neither the OpenCode Go key nor the Matrix password appears in it

### Requirement: Matrix gateway for pim only

Hermes SHALL log in to Tuwunel on nuremberg.pimsnel.com as `@hermes` and
SHALL respond only to the Matrix users on its allowlist, which contains
pim.

#### Scenario: pim writes to the bot

- **WHEN** pim sends `@hermes` a direct message
- **THEN** Hermes replies in that room

#### Scenario: Someone else writes to the bot

- **WHEN** another account on the server messages `@hermes`
- **THEN** Hermes does not act on the message

### Requirement: Dashboard over nebula with a token

The Hermes dashboard SHALL listen on peterspav's nebula address only and
SHALL require the session token from agenix. It SHALL appear in lobby.

#### Scenario: Opening the dashboard

- **WHEN** pim opens the dashboard URL from a mesh member and supplies the
  token
- **THEN** the dashboard loads

#### Scenario: From the LAN

- **WHEN** a device without nebula requests the dashboard port on
  peterspav's LAN address
- **THEN** nothing answers

#### Scenario: In lobby

- **WHEN** pim runs `lobby show hermes`
- **THEN** it shows the dashboard URL on peterspav

### Requirement: No hidden OpenRouter dependency

Tools that call OpenRouter independently of the configured provider SHALL be
disabled.

#### Scenario: Tool selection

- **WHEN** Hermes plans a task that would use vision, web summarization or
  mixture of agents
- **THEN** those tools are not available to it

### Requirement: peterspav stays awake

peterspav SHALL NOT suspend on lid close or when idle.

#### Scenario: Lid closed

- **WHEN** the lid of peterspav is closed
- **THEN** the machine keeps running and Hermes stays reachable

#### Scenario: Idle at the login screen

- **WHEN** peterspav sits at the GDM login screen for an hour
- **THEN** it has not suspended

### Requirement: Hermes state is backed up

Hermes' state directory SHALL be backed up to piethein with restic, from a
consistent copy of any live database files.

#### Scenario: Restore after reinstall

- **WHEN** peterspav is reinstalled and the latest snapshot is restored
- **THEN** Hermes starts with its previous memory and skills
