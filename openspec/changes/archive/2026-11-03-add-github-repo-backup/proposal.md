## Why

The GitHub repositories of `mipmip` and the organizations Pim works in exist
only on GitHub and on whichever laptop happens to have a checkout. Nothing
copies them to hardware Pim owns, so a lost account, a deleted organization or
a force-push upstream can take work with it. hip already knows how to clone
and update every repository of a set of owners; it only has to run somewhere
unattended.

## What Changes

- Run `hip sync` daily on dapperehaan as a dedicated system user, with a
  config generated by Nix that is separate from the laptop config.
- Back up every non-fork repository (archived included) of `mipmip` and of
  every organization Pim belongs to, except `nix-community`. New
  organizations are picked up without a config change.
- Clone over HTTPS with a GitHub token from agenix, as plain git (not jj).
- Add the checkout directory as a new restic dataset, `dapperehaan-repos`,
  so history that disappears upstream stays recoverable from snapshots on
  piethein.

## Capabilities

### New Capabilities

- `github-repo-backup`: unattended, scheduled copy of Pim's GitHub
  repositories onto dapperehaan with hip, including scope, authentication
  and failure reporting.

### Modified Capabilities

- `host-backups`: the configured backup targets gain dapperehaan's
  `dapperehaan-repos` dataset.

## Impact

- New NixOS module, imported by `modules/HOSTS/dapperehaan-server/configuration.nix`.
- `secrets/secrets.nix` and a new `secrets/hip-backup-github-token.age`
  (recipients: pim, dapperehaan).
- dapperehaan's restic `datasets` gains `dapperehaan-repos`; the
  `flake.resticRepos` registry and the Backrest console pick it up.
- Disk: about 13 GB on dapperehaan's `/` (61 GB free), measured on
  2026-10-30 as 731 non-fork repositories, 6.5 GB packed.
- A GitHub classic PAT with `repo` and `read:org`, SSO-authorized for the
  TechNative organizations.
