## Purpose

Keep a copy of Pim's GitHub repositories on dapperehaan, refreshed daily by
hip and backed up to piethein with restic.

## ADDED Requirements

### Requirement: Daily unattended sync on dapperehaan

dapperehaan SHALL run `hip sync` once a day from a systemd timer, as the
dedicated system user `hip-backup`, with its configuration, cache and
checkouts under `/var/lib/hip-backup`. A missed run SHALL be caught up after
boot.

#### Scenario: Scheduled run

- **WHEN** the daily timer fires
- **THEN** `hip sync` runs as `hip-backup`
- **AND** missing repositories are cloned and existing ones fast-forwarded
  under `/var/lib/hip-backup/repos`

#### Scenario: Host was off at the scheduled time

- **WHEN** dapperehaan boots after missing a scheduled run
- **THEN** the sync runs once shortly after boot

### Requirement: Backup scope

The backup SHALL cover every non-fork repository, archived ones included, of
`mipmip` and of every organization Pim belongs to, except `nix-community`.
Organizations Pim joins later SHALL be included without a configuration
change.

#### Scenario: Own and organization repositories

- **WHEN** the sync completes
- **THEN** each non-fork repository of `mipmip` and of every organization
  except `nix-community` has a checkout under `/var/lib/hip-backup/repos`

#### Scenario: Forks and nix-community left out

- **WHEN** the sync completes
- **THEN** no fork and no `nix-community` repository has a checkout

#### Scenario: Newly joined organization

- **WHEN** Pim joins a new organization and the next sync runs
- **THEN** that organization's non-fork repositories are cloned

### Requirement: Configuration separate from the laptop setup

The hip configuration for the backup SHALL be generated by Nix and SHALL NOT
read or change pim's own `~/.config/hip` or anything under `/home/pim`.
Repositories SHALL be cloned as plain git.

#### Scenario: Independent configuration

- **WHEN** the backup sync runs
- **THEN** hip reads a configuration from the Nix store, not from `/home/pim`
- **AND** the checkouts contain `.git` and no `.jj`

### Requirement: Token-based authentication from agenix

A GitHub token SHALL be supplied from an agenix secret readable only by root
and the service. hip SHALL use it for the API, and git SHALL use it for
cloning and fetching over HTTPS. No SSH key SHALL be needed for the sync.

#### Scenario: Private organization repository

- **WHEN** the sync reaches a private repository of an organization
- **THEN** it is listed and cloned using the token from agenix

#### Scenario: Secret not in the store

- **WHEN** the system closure is inspected
- **THEN** the token does not appear in any store path

### Requirement: Failures are visible

A run in which any repository fails SHALL leave the systemd service in the
failed state. A failure in one repository SHALL NOT stop the others from
being synced.

#### Scenario: One repository cannot fast-forward

- **WHEN** a repository was force-pushed upstream and cannot fast-forward
- **THEN** the other repositories are still synced
- **AND** the service ends in the failed state, with the repository named in
  its journal

### Requirement: Checkouts are backed up to piethein

`/var/lib/hip-backup/repos` SHALL be a restic dataset of dapperehaan named
`dapperehaan-repos`, so a repository whose history disappears upstream stays
recoverable from earlier snapshots.

#### Scenario: Upstream history removed

- **WHEN** a branch or repository disappears on GitHub after it was synced
- **THEN** its earlier state is restorable from a `dapperehaan-repos` snapshot
