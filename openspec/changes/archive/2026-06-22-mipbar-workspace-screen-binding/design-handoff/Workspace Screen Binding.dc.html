Indicator

Resolve each workspace's monitor from the Hyprland event socket (workspaces / monitors) and draw a 2.5px underline in that monitor's accent. Map monitor name → a stable accent (config map, falling back to a hashed hue) so colours stay consistent across reloads.

Screen picker

Specs read from hyprctl monitors -j: description (model), active mode, connector. The product image keys off device type — laptop for eDP, monitor otherwise — and can be swapped for a real photo matched on model string. Selecting a row runs hyprctl dispatch moveworkspacetomonitor 6 NAME.
